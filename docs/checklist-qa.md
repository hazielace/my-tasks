# Checklist reutilizable para revisar my-tasks

Este procedimiento se utilizará para crear una Skill propia del equipo. No incluye pasos para modificar código.

1. Ejecutar las pruebas disponibles y registrar cuántas pasaron/fallaron.
2. Revisar que el progreso cuente solo tareas `done` (3/8 = 38%).
3. Probar alta de tarea, cambio de estado, búsqueda y filtros.
4. Confirmar persistencia al recargar, cuando exista acceso a navegador.
5. Comprobar que la consola no muestre errores y que el tablero funcione a 390 px.
6. Informar por separado **verificado**, **falló** y **no se pudo comprobar**.
7. No cambiar archivos al realizar esta revisión; reportar primero.
