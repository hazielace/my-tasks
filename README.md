# my-tasks

Proyecto inicial para una capacitación práctica con agentes de programación.

**En este punto no hay aplicación.** La construiremos en vivo a partir de `docs/brief.md` con Codex CLI.

Tecnología propuesta: Node.js 20+, HTML, CSS y JavaScript; sin paquetes externos. La aplicación se iniciará con `node server.mjs` después de generarla.

La plantilla de `AGENTS.md` está en `../02_PLANTILLAS/AGENTS.md` para copiarla durante la explicación de contexto.
